# Безопасность

- Всё, что пришло снаружи, проверять на границе: тело запроса к службе, событие хука на stdin моста, сообщение из сокета.
- В исходник AppleScript и в команды оболочки подставлять только проверенные значения (например, путь `/dev/ttys…`), никогда текст из сессии.
- В `~/.claude/settings.json` человека трогать только свои записи с меткой `# topbar-managed`; чужие хуки и настройки оставлять как были.
- Сокет моста — только для владельца Mac: каталог `0700`, файл `0600`.
- Автору уходит только то, что перечислено в окне согласия, и только после согласия. Содержимое сессий, файлов, проектов и значков не отправляется никогда.
- Не писать в журнал пароли, токены и личные данные (IP, имя, текст отзыва).
- Служба: адрес клиента — только из доверенного заголовка (`CLIENT_IP_HEADER`) или цепочки прокси; приёмные точки — с лимитом частоты и размера тела; секреты сравнивать за постоянное время.
