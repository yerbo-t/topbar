# Тесты

- Проверять поведение, а не устройство.
- После правки гонять один класс или файл, а не всё: `swift test --filter <Имя>Tests`, из `server/` — `node --test test/<файл>.test.ts`.
- Тесты есть только у `TopbarCore` и `server/`. Логику, которую надо проверить, выносить в ядро чистыми функциями; оболочку `Sources/topbar` (окна, строка меню, доступ) проверять запуском собранного приложения.
- Тест не пишет и не читает настоящие `~/.claude` и `~/Library/Application Support/topbar` и не открывает настоящий сокет: только временные папки (`Fx.tempDir()`), `Store(":memory:")` и данные в памяти.
- Нестабильный тест — починить или удалить, а не перезапускать до зелёного.
- Подменять только границы системы (сеть, файлы, часы, случайность); в остальном — настоящий код.
- Один тест — одно поведение; несколько `XCTAssert` внутри него — нормально. Имя описывает поведение: `testDetachedHeadGivesNil`.
- Никаких `XCTAssertTrue(true)` и проверок «вызвали» без проверки, с чем.
