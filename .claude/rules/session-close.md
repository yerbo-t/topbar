# Закрытие сессии с острова

- В строке сессии раскрытого острова под курсором вместо точки статуса — крест. Первое нажатие превращает его в красное «Закрыть?», второе закрывает; увёл курсор — вопрос снимается.
- Сессию во вкладке Ghostty или Terminal крест закрывает вместе с вкладкой (с ней завершается и Claude). Остальные сессии (Claude в VS Code, неизвестный терминал, iTerm2 — не проверен) только убираются с острова и возвращаются со своим следующим событием.
- Вкладку закрываем, только если процесс сессии жив и сидит именно в ней: номера tty переиспользуются.

**Почему:** владелец 2026-11-12: «добавь кнопку … чтобы закрыть сессию, если это вкладка — то вкладку закроет»; в вопросе выбрал «крест слева в строке», «второе нажатие» и для не-вкладок «только убрать из списка».
