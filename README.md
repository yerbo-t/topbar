# topbar

Нативное macOS-приложение, превращающее вырез (notch) MacBook в Dynamic Island: один тихий оверлей
со статусом сессий Claude Code и кнопками «разрешить / отклонить» прямо из выреза. Ориентиры — vibeisland.app и notchy.dev.
Медиа, системные HUD и быстрые инструменты в MVP не входят (см. «Что НЕ делаем» в спеке).

Статус: discovery. Спека — `docs/specs/`, план — `docs/plans/`.
