# topbar

Остров в вырезе MacBook для Claude Code: видно, какие сессии работают, ждут и закончили, а «Разрешить» и «Отклонить» нажимаются прямо
из выреза. Заодно: сворачивание значков строки меню одной кнопкой, список всех значков и плеер на острове.

Нужен Mac с вырезом, macOS 14 или новее и Claude Code.

Сайт: https://topbar.finea.kz

## Установка

1. Скачайте [topbar.dmg](https://topbar.finea.kz/download) (то же самое лежит в [релизах GitHub](https://github.com/yerbo-t/topbar/releases/latest)) и перетащите topbar в «Программы».
2. Первый запуск. Приложение подписано автором, а не Apple, поэтому macOS покажет окно «Файл topbar не был открыт». Нажмите
   «Готово», откройте «Системные настройки» → «Конфиденциальность и безопасность», прокрутите вниз до раздела «Безопасность»,
   нажмите «Всё равно открыть» рядом с сообщением про topbar, введите пароль и в следующем окне нажмите «Открыть». Либо одной
   командой в Терминале: `xattr -dr com.apple.quarantine /Applications/topbar.app && open /Applications/topbar.app`.
3. Откроется окно «Настройка topbar»: оно по шагам объясняет, что включить (хуки Claude Code, доступ к значкам, управление терминалом,
   автозапуск), и само ставит галочки. Перед записью хуков приложение покажет точную разницу в настройках Claude Code. Окно можно
   открыть снова: правый клик по знаку topbar → «Меню» → «Настройка и подсказки».

Разрешения запрашиваются по необходимости: «Универсальный доступ» нужен только для списка значков строки меню, «Автоматизация»
только чтобы переходить к нужной вкладке Ghostty, Terminal или iTerm2 (остальные терминалы работают без неё).

## Как пользоваться

Клик по знаку topbar прячет значки левее него и возвращает их (сами они не прячутся). Правый клик открывает настройку значков:
булавка закрепляет значок (он попадает в ряд над сессиями на раскрытом острове, и нажатие на него нажимает настоящий значок, даже
спрятанный), глаз убирает значок из списка; системные значки (часы, батарея, Wi‑Fi) в списке не показываются. Внизу кнопка «Меню».
Клик по сессии в острове открывает её терминал, клик по обложке в плеере — приложение, из которого играет музыка.

Когда Claude задаёт вопрос с вариантами, он появляется на острове кнопками: нажатие отвечает Claude без перехода в терминал.
Свободный текст и вопросы с картинками-превью остаются в терминале («Открыть в …» или «Позже»).

## Обновления

Приложение раз в 6 часов смотрит ленту обновлений на GitHub. Новая версия не ставится сама: приходит уведомление, в меню появляется
«Обновить до …», в списке значков есть кнопка «Обновить». Окно покажет, что нового; подпись обновления проверяется перед установкой.

## Что отправляется автору

По умолчанию ничего. При первом запуске окно спросит, сообщать ли автору о том, что вы пользуетесь приложением, и покажет, что именно
уйдёт: имя (если введёте), модель Mac и процессор, объём памяти, версии macOS и topbar, язык системы, случайный номер установки.
Сервер при этом видит ваш IP-адрес. Содержимое сессий, файлов, проектов и значков не отправляется никогда. Отказаться и посмотреть,
что отправляется, можно в меню приложения в любой момент. Кнопка «Написать отзыв…» отправляет только то, что вы сами написали.
Если скачать приложение по ссылке службы автора, он увидит IP и браузер; прямое скачивание с GitHub IP не раскрывает.
Удалить свои данные можно по просьбе автору.

## Сборка из исходников

```
swift test                         # тесты
scripts/build-app.sh --install     # собрать build/topbar.app и поставить в ~/Applications
```

Выпуск для раздачи: `scripts/setup-signing.sh` (один раз: ключи и сертификат), `scripts/release.sh` (архив, образ, лента),
`scripts/publish.sh --yes` (выкладка в релизы GitHub). Служба со списком установок и отзывов — в `server/`.
Спека и планы — в `docs/`.
