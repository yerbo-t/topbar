topbar — остров в вырезе MacBook для Claude Code

УСТАНОВКА
1. Перетащите topbar в «Программы» (рядом лежит ярлык).
2. Первый запуск. Приложение подписано автором, а не Apple, поэтому macOS покажет предупреждение — это нормально.
   • Откройте «Системные настройки» → «Конфиденциальность и безопасность», прокрутите вниз, нажмите «Всё равно открыть»
     рядом с сообщением про topbar и подтвердите паролем.
   • Либо в Терминале одной строкой:  xattr -dr com.apple.quarantine /Applications/topbar.app
3. Следуйте подсказкам: подключить хуки Claude Code (покажет точную разницу в настройках до записи), по желанию сообщить автору,
   что вы пользуетесь приложением.

РАЗРЕШЕНИЯ (по запросу, когда понадобятся)
• «Универсальный доступ» — только для списка значков строки меню.
• «Автоматизация» (Ghostty) — чтобы переходить к нужной вкладке терминала.

Обновления приходят сами. Меню приложения — значок «›» в строке меню, правый клик.
Удаление: «Удалить хуки…» в меню, затем перетащить topbar из «Программ» в корзину.
