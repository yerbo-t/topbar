# Распространение: подпись, автообновление, список установок (2026-11-05)

Решения владельца: подпись своя (самоподписанный сертификат), лента обновлений и файлы — GitHub (отдельный публичный репозиторий только для
релизов) или свой сервер; список «кто установил» — с согласия самих людей.

## Что сделано и проверено

- **Автообновление (Sparkle 2.10.1).** Приложение раз в 6 часов смотрит ленту, скачивает архив, проверяет подпись EdDSA и ставит, когда нет
  открытых запросов разрешений (перезапускается само). Проверено на настоящем обновлении 0.2.0 → 0.2.1 через локальную ленту.
- **Подпись обновлений** — свой инструмент `scripts/tools/release-tool.swift` (Ed25519 над байтами файла, лента appcast). Ключ — в
  `~/Library/Application Support/topbar-signing/` (СОХРАНИТЬ КОПИЮ: без него уже выданные копии не примут обновление).
- **Подпись кода** — самоподписанный сертификат «topbar release» в отдельной связке ключей (`scripts/setup-signing.sh`). Требует один раз
  довериться сертификату (запрос пароля системой): `security add-trusted-cert -r trustRoot -p codeSign <папка>/topbar-release-cert.pem`.
  Пока этого не сделано, сборка подписывается ad-hoc, и разрешения слетают при каждой установке.
- **Сборка выпуска** — `scripts/release.sh`: zip для обновления, dmg для скачивания (с памяткой про первый запуск), appcast.xml. Ничего не
  публикует.
- **Значок** — `scripts/AppIcon.icns` (рисуется `scripts/tools/make-icon.swift`).
- **Список установок и отзывы** — `server/` (Hono + SQLite): имя, модель Mac, процессор, память, macOS, язык, IP; ссылка скачивания с
  записью IP; счётчики GitHub; отзывы из приложения. Согласие и перечень отправляемого — в окне при первом запуске. Проверено сквозным
  прогоном (запись дошла с моделью Mac17,2 и языком).

## Что требует решения владельца

1. Довериться сертификату (команда выше).
2. Репозиторий `yerbo-t/topbar` (публичный, MIT) создан не будет, пока владелец не скажет «да» на выкладку; перед первым push проверить историю.
3. Сервер списка установок: поддомен выбран («свой поддомен»), название ещё не названо; без него сборки идут без согласия и отзывов.
