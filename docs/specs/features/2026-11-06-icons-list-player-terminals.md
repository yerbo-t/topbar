# Список значков, плеер, терминалы, вид как в демо — mini-spec

## Что меняем
1. **Список значков.** Вместо жёлтой подписи «спрятан» у каждого значка кнопка-глаз. Закреплённые всегда сверху (в порядке владельца), ниже остальные: кто последним был в работе (нажат в списке или стал активным приложением) — выше; ниже свёрнутая группа «Скрытые (N)», куда глаз убирает значок. Закрепление скрытого значка возвращает его из скрытых, скрытие закреплённого открепляет.
2. **Плеер.** Обложка с названием — кнопка «открыть приложение, из которого играет музыка» (плюс маленькая стрелка справа от названия); после нажатия остров сворачивается.
3. **Терминалы.** Переход к сессии и признак «владелец смотрит на сессию» работают не только в Ghostty и VS Code: хост берётся из `__CFBundleIdentifier` (а если его нет — по цепочке родительских процессов до приложения с окном). Точный переход к вкладке и окну — Terminal и iTerm2 (AppleScript по tty, запрос «Автоматизация» один раз на каждое приложение); остальные (Warp, WezTerm, kitty, Alacritty, Hyper, Cursor, Windsurf, JetBrains…) — приложение выходит вперёд. Окно Ghostty и VS Code ведёт себя как раньше.
4. **Вид как в демо на сайте.** Остров, список сессий, карточка разрешения, плеер и список значков приводятся к виду анимации на `topbar.finea.kz`: зелёная «Разрешить» с тёмным текстом и тёмная «Отклонить» с тонкой рамкой, скруглённые кнопки с нажатием «сжатием», строки с мягкой подсветкой, крупная обложка плеера и пять полос эквалайзера, плавное появление содержимого строками с задержкой после раскрытия острова. При «Уменьшить движение» — без движения.

## Зачем
Список значков нужен, чтобы своим местом управлять самому: важное закреплено, редкое убрано, остальное само поднимается по недавности. Кнопки «закрепить»/«спрятан» выглядели как неработающие. Плеер показывает музыку, но вести к её приложению не умел. Ссылка «Перейти к сессии» молча не работала в Terminal и любых терминалах кроме Ghostty. Приложение должно выглядеть так, как обещает сайт.

## Что НЕ меняем
- Сворачивание значков в самой строке меню: прячется всё левее знака topbar; глаз у значка строку меню не трогает (система не позволяет прятать чужой значок отдельно; перестановка чужих значков имитацией ⌘-перетаскивания в эту работу не входит).
- Доступ «Универсальный доступ», подпись, обновления, служба, сайт.
- Логика статусов сессий, очередь запросов, хуки.
- Расположение острова и «уши» у выреза, размеры экранов.

## Влияние на схему БД
Нет. Схема сессий в сокете: у `Session` и сообщения моста новое необязательное поле `hostBundleId` (старые сообщения и сохранённые сессии без поля читаются как раньше). Настройки приложения (`UserDefaults`): `menuBarEyeHidden` (скрытые ключи значков), `menuBarLastUsed` (ключ → время).

## Сценарий приёмки
- Владелец открывает список значков → закреплённые сверху, ниже остальные по недавности, внизу «Скрытые (N)» свёрнуты; нажимает глаз у значка → тот уходит в «Скрытые» и пропадает из основного списка; нажимает глаз в «Скрытых» → значок возвращается; закрепляет/открепляет → порядок меняется сразу и сохраняется после перезапуска.
- Играет музыка → в острове нажать обложку или стрелку → приложение-источник выходит вперёд, остров сворачивается.
- Сессия Claude Code в Terminal и в iTerm2 → клик по сессии в острове → нужная вкладка выходит вперёд (после разового разрешения «Автоматизация»); в Warp/WezTerm/kitty/Alacritty → окно приложения выходит вперёд.
- Карточка разрешения: «Разрешить» зелёная, «Отклонить» тёмная с рамкой, при нажатии кнопка сжимается; раскрытие острова — пружина, строки появляются по очереди.
