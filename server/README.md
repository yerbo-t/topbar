# topbar-installs

Маленькая служба для автора topbar: принимает от приложения запись «пользуюсь» (только от тех, кто согласился в окне при первом
запуске) и отзывы (только когда человек сам нажал «Отправить»), ведёт ссылку для скачивания и показывает всё это одной страницей.

Что сохраняется: имя (если человек ввёл), модель Mac, процессор, объём памяти, версии macOS и topbar, язык системы, **IP-адрес**,
случайный номер установки, время первого и последнего сообщения, число запусков; у отзывов — текст и как ответить; у скачиваний по
ссылке — IP и название программы-браузера. Содержимого сессий, файлов, проектов и значков приложение не отправляет.

- `POST /api/ping` — запись «пользуюсь» (JSON, до 8 КБ, до 30 в минуту с адреса).
- `POST /api/feedback` — отзыв.
- `GET /download` — записывает, кто пришёл, и ведёт на последний релиз GitHub. Эту ссылку, а не прямую, стоит давать людям.
- `GET /admin` — страница: установки, отзывы, скачивания, счётчики GitHub. Логин `admin`, пароль из `ADMIN_PASSWORD`. `GET /admin.json` — то же в JSON.
- `GET /health` — проверка.

## Запуск

Node 24+. `ADMIN_PASSWORD=<не короче 12 символов> npm start`. Данные — SQLite в `DATA_DIR` (по умолчанию `./data`).
Docker: том на `/data`, порт 3000. Переменные:

| Переменная | Что делает |
| --- | --- |
| `ADMIN_PASSWORD` | пароль страницы `/admin` (обязательна, от 12 символов) |
| `DATA_DIR` | где лежит база (в Docker `/data`) |
| `GITHUB_REPO` | например `yerbo-t/topbar`: включает счётчики скачиваний GitHub и задаёт ссылку `/download` |
| `DOWNLOAD_URL` | куда вести `/download`, если не GitHub |
| `TRUSTED_PROXY_HOPS` | сколько прокси стоит перед службой (за Coolify/Traefik — 1, по умолчанию 1); от этого зависит, какой IP считается адресом клиента |

Адрес службы вшивается в приложение при сборке переменной `TOPBAR_SERVER_URL`. Менять его у уже розданных копий нельзя, поэтому
берите постоянный адрес (свой поддомен).

## Удалить данные человека по его просьбе

Номер установки он видит в меню приложения («Что отправляется…»), первые 8 символов есть в списке. Удаление записи и отзывов:
`node -e "import('./src/store.ts').then(({Store})=>new Store(process.env.DATA_DIR+'/installs.sqlite').forget('ПОЛНЫЙ-НОМЕР'))"`.

Тесты: `npm test`.
