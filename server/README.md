# topbar-installs

Маленькая служба: принимает записи «пользуюсь topbar» (только от тех, кто согласился в самом приложении) и показывает автору
список: имя (если человек его ввёл), версия, macOS, когда впервые и в последний раз, сколько запусков. IP-адреса не сохраняются.

- `POST /api/ping` — запись от приложения (JSON, до 4 КБ, до 30 в минуту с адреса).
- `GET /admin` — страница со списком, закрыта Basic-авторизацией: логин `admin`, пароль из `ADMIN_PASSWORD`.
- `GET /admin.json` — то же в JSON. `GET /health` — проверка.

Запуск: `ADMIN_PASSWORD=<не короче 12 символов> npm start` (Node 24+). Данные — SQLite в `DATA_DIR` (по умолчанию `./data`).
Docker: том на `/data`, переменная `ADMIN_PASSWORD`, порт 3000. Адрес записи (`https://…/api/ping`) вшивается в приложение при сборке
переменной `TOPBAR_PING_URL`. Тесты: `npm test`.
