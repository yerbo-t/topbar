# topbar-installs

Маленькая служба для автора topbar: принимает от приложения запись «пользуюсь» (только от тех, кто согласился в окне при первом
запуске) и отзывы (только когда человек сам нажал «Отправить»), ведёт ссылку для скачивания и показывает всё это одной страницей.

Что сохраняется: имя (если человек ввёл), модель Mac, процессор, объём памяти, версии macOS и topbar, язык системы, **IP-адрес**,
случайный номер установки, время первого и последнего сообщения, число запусков; у отзывов — текст и как ответить; у скачиваний по
ссылке — IP и название программы-браузера. Содержимого сессий, файлов, проектов и значков приложение не отправляет.

- `POST /api/ping` — запись «пользуюсь» (JSON, до 8 КБ, до 30 в минуту с адреса).
- `POST /api/feedback` — отзыв.
- `GET /download` — записывает, кто пришёл, и ведёт на последний релиз GitHub. Эту ссылку, а не прямую, стоит давать людям.
- `GET /admin` — страница: сводка по версиям (сколько устройств на какой), устройства детально, отзывы, скачивания, счётчики GitHub. Логин из `ADMIN_USER` (по умолчанию `admin`), пароль из `ADMIN_PASSWORD`. `GET /admin.json` — то же в JSON.
- `GET /health` — проверка.

## Запуск

Node 24+. `ADMIN_PASSWORD=<не короче 10 символов> npm start`. Данные — SQLite в `DATA_DIR` (по умолчанию `./data`).
Docker: том на `/data`, порт 3000. Переменные:

| Переменная | Что делает |
| --- | --- |
| `ADMIN_PASSWORD` | пароль страницы `/admin` (обязательна, от 10 символов) |
| `ADMIN_USER` | логин страницы `/admin`; не задан — `admin` |
| `DATA_DIR` | где лежит база (в Docker `/data`) |
| `CLIENT_IP_HEADER` | заголовок, из которого брать адрес клиента, например `cf-connecting-ip`. **Для topbar.finea.kz нужен именно он**: Coolify/Traefik подменяют `X-Forwarded-For`, и без него в списке у всех будет внутренний адрес сервера. Включайте, только если службу не открывают в обход Cloudflare: иначе заголовок можно подделать |
| `GITHUB_REPO` | например `yerbo-t/topbar`: включает счётчики скачиваний GitHub и задаёт ссылку `/download` |
| `DOWNLOAD_URL` | куда вести `/download`, если не GitHub |
| `TRUSTED_PROXY_HOPS` | сколько прокси стоит перед службой; от этого зависит, какой IP считается адресом клиента. За одним Coolify/Traefik — 1 (по умолчанию). Если задан `CLIENT_IP_HEADER` и в нём настоящий IP, цепочка не используется. После развёртывания отправьте тестовую запись и проверьте на `/admin`, что виден ваш адрес, а не внутренний (`10.…`) или Cloudflare (`188.114.…`, `172.…`) |

Адрес службы вшивается в приложение при сборке переменной `TOPBAR_SERVER_URL`. Менять его у уже розданных копий нельзя, поэтому
берите постоянный адрес (свой поддомен). Для topbar это `https://topbar.finea.kz`: у зоны `finea.kz` подстановочная запись DNS через Cloudflare, отдельную запись добавлять не нужно, в Coolify для приложения указывается домен `topbar.finea.kz`.

## Удалить данные человека по его просьбе

Номер установки он видит в меню приложения («Что отправляется…»), первые 8 символов есть в списке. Удаление записи и отзывов:
`node -e "import('./src/store.ts').then(({Store})=>new Store(process.env.DATA_DIR+'/installs.sqlite').forget('ПОЛНЫЙ-НОМЕР'))"`.

## Страница-витрина

Служба отдаёт лендинг на `/` из папки `public/` (один `index.html` без внешних зависимостей, картинки в `public/assets/`). Кнопки «Скачать» ведут на `/download`, поэтому каждое скачивание попадает в список. Страница кэшируется на 5 минут, картинки на сутки; после правки откройте её с любым `?v=…` или сбросьте кэш браузера. Файлы вне `public/` не раздаются.

Тесты: `npm test`.
